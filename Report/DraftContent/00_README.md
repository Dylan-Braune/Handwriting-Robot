# Draft report content — how to use this folder

These files are raw content drafts for the final report's Part 3 (Main
report), written in the required third-person, past-tense, formal style
per Appendix 4 of the study guide. They are NOT formatted, paginated, or
placed into the official template yet — that step (Section C of Appendix
4: fonts, heading sizes, numbering, margins, figure/table captions, the
compulsory Table 1/Table 2 formats) still needs to happen once the
content itself is finalised, by pasting these into `FinalReportTemplate_2026.doc`.

Files:
- `01_literature_study.md` — background/context + how it was applied (report section 1)
- `02_approach.md` — design alternatives + preferred solution (section 2)
- `03_design_and_implementation.md` — the largest section; per-subsystem design procedure, theory, and reasoning (section 3)
- `04_results.md` — summary table + four qualification tests, with real measured numbers (section 4)
- `05_discussion.md` — critical evaluation, unsolved problems, strong points, failure conditions, and the five compulsory "considerations" subsections (section 5)
- `06_conclusion.md` — summary, contribution, future work (section 6)

## What still needs your own input (search for "DRAFT NOTE")

Every place a `[DRAFT NOTE: ...]` appears marks something that could not
be responsibly filled in from the project's code/chat history alone —
mostly: (a) the physical gantry build details (enclosure, ergonomics,
wiring safety) that only exist in the hardware itself, not the
repository; (b) the personal/contribution content in section 6.3, which
by the study guide's own rule must be your own first-hand account, not
reconstructed by anyone else; (c) consent/ethics-clearance facts about
the two personal handwriting contributors, which only you know; and
(d) numbers in section 4/5 that were still being actively improved when
this draft was written (the per-author legibility tuning work) — these
are flagged to be refreshed with final numbers once that work concludes.

## Page budget sanity check

Appendix 4 requires the *main report* (Part 3 only, sections 1-6) to be
50-70 pages. The current draft content, once placed into the template's
required font sizes (18pt section headings, 12pt body text, single
line spacing, 25mm margins), is a first pass at *content* only and has
not been checked against that page count — expect to need to expand
section 3 in particular (guideline: 30-40 pages on its own) with actual
figures, equations set out per the template's numbering convention, and
more worked detail once the placeholders above are filled in.
