FAIL: ctc  T6 B1 C3 target[] (empty label, S==1) / dlogits

The only failure is a shape bug in CtcLoss, not a wrong derivative:
for an EMPTY label sequence the extended sequence is ext=[0], so S==1, but
    prev2 = np.concatenate(([NEG,NEG],logAlpha[t-1,:-2]))
    nextMinus2 = np.concatenate((nxt[2:],[NEG,NEG]))
are built length 2 instead of length S, so the assignment
`logAlpha[t] = combined+lp[t,ext]` raises a ValueError. For every S>=3 the
same expressions come out length S and the gradient is correct, which is why
all non-empty targets pass. Real-world impact is limited (a transcription
line with zero characters never appears in the training data), but the
function is not safe against one.

Separately (not counted as a configuration): when the label is too long for
the input length (2*L+1 > T) no valid alignment exists, CtcLoss returns
loss=inf and a gradient containing nan. That is the mathematically correct
answer for an infeasible alignment and matches what torch reports, but it
means such samples must be filtered before training rather than relied on
to produce a finite gradient.
