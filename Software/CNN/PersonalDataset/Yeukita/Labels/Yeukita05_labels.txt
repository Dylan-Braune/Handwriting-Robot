1. Storage array
8x8x1 chips form one bank
- Capacity: 8 chips x 64 bits = 512 bits (64 bytes)
- Organisation: chips arranged in parallel. All 8 chips receive the same
address and write enable signals.
- Result: everytime an address is provided, array outputs 8 bits (1 byte).
Since a cache line is 4 bytes, it takes 4 locations in array to store
one "line"
2. Input from CPU
- Index (4 bits) - goes to address pins of mem chips to correct line
- tag (2 or 4) - goes to comparator
- word offset (2 bits) - goes to output multiplexer to pick specific byte from
