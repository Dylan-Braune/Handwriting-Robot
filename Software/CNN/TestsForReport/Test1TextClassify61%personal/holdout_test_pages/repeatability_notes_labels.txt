0	Repeatability
1	Every run is seeded deterministically,
2	any data point can be regenerated
3	in isolation using the formula:
4	(seed + 1000* experiment + 10* condition index
5	+ run index).
6	Limitations
7	- The full sweep is conducted beforehand
8	because 3600 monte carlo runs cannot
9	be done live, and in the demo
10	only 10 runs per parameter value per
11	experiment so the accuracy might not
12	be as perfect as the offline runs
13	- The DUCM is only formally verified
14	for the practical 2 and existing research
15	2014 Test Case I, and not for the
16	full parameter sweep done in this practical.
17	Number of Run considerations
18	The optimal test's standard error is
19	sigma_M ~ 1/sqrt(Nmc) (eq 1.5.3-13) in the textbook,
20	so by halving the Nmc scales the sigma_M
21	up, and therefore scales M down
22	Therefore conditions close to the
23	threshold could flip the accept or reject outcomes
