Gantry calibration Checking...

The gantry must be calibrated (homes both axes, measures the real steps-per-mm, and parks at a safe start position) before anything below can be used.

Generation never touches the machine: the text is synthesised, rendered, read back and written to a file entirely in software. Only Send to gantry needs hardware, and offline mode disables that one button.

1. What to write

Higher = more legible & distinctive, but slower (roughly linear). 20 is a good default; 30 was used for the final measured accuracy numbers on the Model & Style page.

line 1 ruling mm

On the ruling the lines are pushed to 8.4 mm apart, which is closer than the letters were laid out for, so neighbouring ascenders and descenders occasionally touch. Ink that touches is one shape to the segmenter: it cuts the two lines as one and classifies the wrong picture. The ruling still sizes the letters either way — only the spacing changes.

Each job is written one ruled line lower than the last, so a sheet fills up instead of everything landing on the same spot. The diagram shows where it goes.

✍ Writing (pen down) 900 mm/min 15.0 mm/s

Lower if tight curves come out rounded off — an e drawn too fast overshoots its own loop. This is the one that costs accuracy.

↗ Traversal (pen up) 2400 mm/min 40.0 mm/s

Nothing is being drawn while the carriage crosses the page, so raising this buys back the time a slower writing speed costs.

⬆ Wait after pen UP 350 ms

Dead time before the carriage is allowed to move away. The lift only has to clear the paper, so this is the safer of the two to cut.

⬇ Wait after pen DOWN 350 ms

Dead time before drawing starts. Cut this too far and the first millimetre of each stroke is drawn while the nib is still seating — it shows up as faint stroke starts, not as an obvious failure.

Stop abandons the rest of the G-code, lifts the pen and drives back to the corner, in that order — the pen comes up before the carriage moves so the trip home does not draw across the page. It can be pressed while a job is running. Whatever was being drawn is left unfinished, so do not measure it.
