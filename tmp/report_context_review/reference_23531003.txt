1. Literature study
A artifical neural network (ANN) refers to a computational model that models the behaviour
of biological neurons in order to create relationships between input data and outputs [ 1].
These networks are modelled on the biological neural networks that the brain uses for pattern
recognition. Relationships between "neurons" are defined by the weights and biases that
connect them to one another and are set by training the network with data and correcting the
weights to more accurately reflect the relationships between inputs and outputs. The neuron
sums the weighted inputs, maps it to a non-linear activation function (used to account for
non-linear relationships [2]) and provides an output. Neural networks are used for speech
recognition [1], cancer research [1] and fraud detection systems.
In most intances, these models are often implemented in the digital domain, as the
size of these networks for more complex tasks can become large. The data required to train
these networks is most often stored in the digital domain. The connections between neurons,
as well as the neurons themselves can be modelled in the analogue domain. This approach is
often used when access to a computer in the envrionment is limited or restricted. An example
is provided by Agnelli et al. [3], who developed an analogue neural network to classify strokes.
In remote places were computers may be limited in power, analogue neural networks can
be considered for implementation rather than buying a more expensive computer. Agnelli
also notes that sensors can be fed directly to the analougue neural network without their data
needing to be converted to a digital value, which can also offer gains in edge computing by
storing inferences made with the data rather than the raw data itself (thereby reducing the
amount of data needed to be stored).
In this implementation of the analogue neural network, the use case was rather defined as digit
recognition. The MNIST dataset was chosen for the training of the network. The use of this
widely avaliable dataset that is often used as a benchmark digital neural networks can be used
for the same purpose in the analogue domain. The use of a public dataset also ensures that the
data was not manipulated to fit the needs of the analogue nature of the implementation.
Due to this project building upon the work of the previous implementation by Koen [4], sufficent
knowledge was required to understand the previous network in order to understand what changes
can be made to create sufficent differentiation between this implementation and the previous
one and improve the system. The two primary points of differentiation considered was either
changing the activation function function used in the neuron or changing the type of neural
network. Both options were investigated before a decision was made regarding which direction
should be taken.
1.1 Neuron Types
The perceptron (also refered to as the McCulloch-Pitt Neuron) is the simple modelling of a neuron
[2]. The perceptron involves the summing of different inputs that are weighted independently
of each other. The sum of these weights is then provided as the input to a non-linear activation
function to map non-linear relationships. The output of this combination is considered the output
of the perceptron, which can then be used as inputs to other neurons or as the output of the
network, depending on it’s location. The visual representation of the concepts mentioned above

potential is lost over time, to allow for decaying back to the neuron’s initial state if it has not

The network can either update it’s weights based on the data that it receives and adjust them
during operation (on-chip training) or train in software and they cannot be changed once they are
translated to the analogue domain (off-chip training) [6] . On-Chip training required components
at higher levels of integration (such as a memistor [7]), which would violate the requirements of
the system and make the project more expensive.
The variation in the architecture emerges when considering how inputs are provided to
the network [5]. The MLP requires the voltages to be constant signals. The input encoding of an
SNN can be done in multiple ways: keeping the input a constant DC, varying the number of
spikes in an interval to reflect the intensity of the input (rate encoding), varying the length of a
spike to reflect input intensity,or the time at which the spike was fired reflecting input intensity
(latency encoding). In the analogue domain, where time is continous, the latency encoding
cannot be considered fesiable as a seperate device would be required to take note of the timing
of the pulse, or it would require much more circuitry. Rate encoding or DC inputs as suitable
options for a purely analogue spiking neural network (SNN).
Reading the outputs of both networks will require distinct methods. In the MLP neuron, the
output neuron with the highest value can be considered the output of the system. In a SNN,
output classification can be done in one of 2 ways, rate encoding or latency encoding. Latency
encoding will require more complex circuitry to measure, as such rate encoding is prefered of
the two options.
1.3 Training
The previous implementation of the project used a Re-LU activation function, and in order to
create differentiation, other activation function’s implementation’s in the analogue domain was
considered. The two options considered was the sigmoid function, as the other option considered
(tanh) did not have reputable implementations in the analogue domian. The sigmoid function is
defined as:
σ(x)= 1
1+e −x.(1)
The sigmoid function can be represented in the analogue domain as a circuit that would require
at least 8 transistors for implementation [8]. The output labeled V is the sigmoid function, with
the reference voltage being used to set the midpoint of the sigmoid function. This presented
the sigmoid function as a possible alternative to the use of the ReLU function that was used
previously.
A SNN can be trained further through backward propagation; however, due to the spik-
ing nature of the neuron as well as the fact that there is no explicit activation function, the
derivative will be 0 at any point except the spike is outputted (where it will be a discon-
tinuity, due to the spike being a step function) ,thus not allowing for backward propagation.
To mitigate this property, a surrogate gradient can instead be used for training purposes
[5]. This function will mimic the gradient of a well-known activation function and use
this to adjust the weights of the SNN such that the accuracy of the system can be increased.
The standard gradients used for MLP systems are applicable for use as surrogates for the SNN [5].

Training an SNN from scratch using a surrogate gradient descent takes much more
time than training an ANN [ 9] and requires the development of dedicated scripts to attempt
the same. In the event that a different activation function approach is chosen over changing
the neuron type, this time spent training the network would be wasted. As such, methods of
converting an exsisting MLP neural network to an SNN were explored. This allowed for the
MLP network developed for comparison purposes to be used for training. The algorithms
suggested by Li et al. [ 9] are created for an integrate and fire (IF) neuron rather than a LIF
neuron, and as such they cannot be used directly. Consequently, another source will need to be
found for use in training the Spiking Neural Network.
Diehl et al.[ 10] provide 2 main startegies that can be used for conversions between the
ANN and the SNN: data-based normalisation and model-based normalisation. These methods
exist to solve the problem of oversaturation, where the spike rate required to represent the
intensity of the input is greater than the rate achieveable in either the analogue or digital domain.
Model-based normalisation is a method that adjusts the weights such that the maximum input
received by a neuron does not exceed the threshold set by the neuron. As such over-activation
cannot occur on any neuron [10]. This approach however, assumes that all neurons or inputs can
simultaneously fire, which may not be the case, so this approach could be an overcorrection.
Furthermore, as this method is applied per layer in the neural network, deeper layers may go
completely quiet due to their weights being substantially scaled so highly to account for previous
normalisation.
Data-based normalisation involves looking at the output of every activation function in
the network and scaling the weights such that the highest output of a neuron would emit a single
spike [10], while taking the maximum input weight(to prevent the neuron from spiking multiple
times).
In the event that an SNN is developed, the data-based normalisation may be considered
in order to prevent the oversaturation. The overcorrection brought about by model-based
normalisation can affect the accuracy quite significantly, especially in a system with the size
contraints that the one proposed has. Diehl et al. [10] suggests Data-Based Normalisation if both
short latencieis and high accuracies are required, which further backs up this decision.
Rather than training the SNN from scratch using a surrogate gradient, the option to convert an
exsisting ANN to an SNN was chosen to reduce training time without losing much accuracy.
The surrogate gradient can be used afterwards to train the SNN further if this is deemed necessary.
Knowledge distillation is a method of training a neural network wherein a larger teacher model
aims to tranfer it’s learnings to a smaller student model [11]. The primary aim is to teach the
student network the complex relationship that the teacher is able to infer through training [11].
The predictions of the teacher network is used alongside the training data in the training of the
student network.
This method was considered for use to train the neural networks in the hopes that it
would increase accuracy, but the limited number of inputs to the network (being restricted to
16) would mean that the teacher’s networks accuracy would not be large enough to increase
the accuracy of the student network (the one to be implemented in the analogue domain)

1.4 Other implementations of Spiking Neural Networks
Asghar et al. [12] created a design for a LIF neuron that they used to classify the MNIST dataset,
achieving a 94% accuracy. Their neuron design proves that an analogue SNN can be used to
classify digits. Their system shows two possible issues that may arise with the system. Firstly,
the implementation used 81 inputs as opposed to the maximum of 16 that this system is allowed
to use. Secondly, their implementation used 141 neurons, which would be a very expensive
circuit to create. Thirdly, their system used 180nm CMOS transistors and a complex neuron that
is not fesiable for design and implementation in the brief amount of time avaliable. Their circuit
uses a Binary Exponential Charge Injector (BECI) to inject a charge into the neuron as required,
which would require complex circuitry to accomplish. Overall, this implementation only shows
fesiability, however however their use of the Schmitt Trigger to generate the spikes was noted.
Ramirez et al. [13] made a single neuron to model the properties. Their use of switches provided
a basis for using switches to implement the reset of the neuron once the voltage exceeds the
threshold. This approach however uses control units in order to control the timing of spike
generation, which violates the third requirement of the system. As such this neuron cannot be
implemented as designed, to create the SNN either.
Inspiration can be taken from each of the neurons mentioned above, but the neuron
will have to be built from first principles to meet the requirements if an SNN is chosen for
implementation.
1.5 MNIST dataset
The MNIST dataset is used to train and test a network. The training dataset contains 60000
samples while the test dataset contains 10000 samples [ 14]. Each image has a resolution of
28x28 (784 inputs per image). All images are black and white images as well as being size
normalised. Each image was also centred by computing the center of mass of the pixels and
translating the image such that the center of mass is at the centre of the image. The pre-processed
nature of the dataset will make it easier to extract features from the images. All digits with their
complete variations (open or closed loop 4’s and 7’s with a line in the middle) is represented in
the dataset. An example of a image in the MNIST dataset is shown in Figure 5.

2. Approach
2.1 Feasability Analysis
Before the neuron was designed, a simulation had to be made to determine if a neural network
with a low number of neurons and 16 inputs was sufficent to classify data points from the MNIST
dataset. A MLP neural network was created with three activation functions being considered
(ReLU, tanh and sigmoid). The tanh and sigmoid were considered as alternative activation
functions to create sufficent differentiation from the previous implementation. The RELU was
created as it was the best activation function for conversion to an SNN [10], in the event that a
SNN was chosen for implementation.
For these 3 networks, different input reduction techniques were explored. The inputs
chosen for use are made up of a few used for letter recongition [15] that could be translateable
to digits, and the remaining catered specifically to digit recognition ([16]). The features were
specifically chosen to maximise the accuracy of the system chosen.
The network simulations were then used to find learning parameters that can maximise
the accuracy of the network through a large monte carlo simulation. Once the optimal RELU
network was found, it was converted to a SNN through the methods obtained from literature
review [5],[10].
In order to create sufficent differentiation between this implementation and the previ-
ous one, the SNN was chosen for implementation over just changing the activation function
using LIF neurons as recommeded by Eshraghian et al. [5].
2.2 Neuron Design
A LIF neuron was designed , simulated, and then built using components avaliable to the PCB
supplier (JLCPCB). A comparison between theoretical expectations and measured results were
iteratively used as feedback to improve the design, with the neuron designed optimised to a lower
size.
2.3 Simulation and Training
The performance of the neuron was recorded and transfered to software in order to train the
network with it’s analogue characteristics, such as operating range as well as the frequency of
the spikes based on the input voltages. The effect this had on accuracy forced changes in the
weight and bias values such that the detrimental effects can counteracted. The weights obtained
from this step were used to create the final weights that would be deployed in the final network.
The behaviour of the neuron was used to create a custom surrogate gradient that mirrored the
behaviour of the neuron rather than a function that may not have been a true representation of
the neuron behaviour.

Once the network was trained to achieve a sufficent accuracy, the type of neural net-
work to be implement had to be considered again. The spiking neuron design was completed to a
sufficent degree, however many questions still remained regarding the summing of these spikes
at the output layer. While a design for a neuron capable of summing this network was developed
and considered, there was not sufficent time to continue to investigate whether this design was
feasible to create a whole neural network. Furthermore, components required to implement a
complete SNN would increase the cost of the final circuit considerably due to an increase in both
the size of the board and the amount of components. As such, the final circuit was implemented
as a hybrid network, with the hidden layer neurons being MLP neurons, and the output layer
neurons being the Spiking Neurons. The two approaches were combined to create a new type of
network were created in order to train this hybrid network.
While neuron reduction techniques were explored, the cost of neuron reduction on ac-
curacy resulted in this not being implemented. The final network was implemented with 20
neurons as originally specified.
2.4 Testing the network
To account for improvements suggested by Koen, a more robust and efficent testing system was
designed. This involved the use of a Digital-To-Analogue Converter (DAC) being used to provide
the input voltages to the circuit, along with the use of microcontrollers to read the spiking outputs
to classify them based on the most amount of spikes in the period of interest. These results were
then used to test the accuracy of the system without a user having to set the input voltages by
hand as it had to be done in Koen’s implementation, thereby allowing for quicker system testing.
As this was not an explict part of the system, rather a interface to interact with the system, the
design is detailed in Appendix C.
2.5 Component Choice and Mapping
As the components used to create the system would be placed by JLCPCB, all components
used had to adhere to the ones they held in stock and meet the requirements of the system. The
resistors that would represent the weights would have to be approximated to the nearest available
value such that the number of distinct resistor values that would need to be purchased is reduced
to it’s lowest possible number.

current mirror [18] would increase circuit size unessarily, with neither of the options offering
an ability to account for negative weights. As such, the Koen summer is a cheap and effective

3.4 Input Selection
The system had to have a minimum of 16 inputs, as such the 784 inputs of the MNIST dataset
had to be reduced to meet this requirement. Three dimensionality reduction techniques were
considered for this approach: averaging of pixels, Principal Component Analysis (PCA) and
feature extraction based on pixel location.
The input intensities must be voltage values that can be outputted to the system. In or-
der to ensure that all values can be outputted by the testing system, a normalisation method was
used, as proposed by Frey et al. [15] that normalises it to the distribution of that feature. This
method mapped intensities to values between 0 and 16, but for the purposes of this system, the
values were mapped such that the maximum value of a particular feature is mapped to 3.2V ,
and the minimum is mapped to 0.1V . The upper bound was chosen due to all 3.3V systems
being able to provide it comfortably, and the lower bound was chosen as 0 means a lack of
information, which is not the case as it does have a intensity, but it is just small. The equation
used to normalise the inputs is:

As each entry in the MNIST dataset contains 784 pixels, to reduce the inputs down to 16, 49
pixels would have to be averaged. This was done by averaging a block of 7x7 down to one value.
The values were then normalised using equation 5.
PCA [ 19] is a method of dimensionality reduction that involves first centring the data,
computing the covariance matrix and then finding k eigenvalue and eigenvectors (wherek is the
dimension to which the input must be reduced to, which for this system is 16). The dataset is
projected to these eigenvectors. The dimensionality reduction is achieved with the formula 6:
Z=X∗W(6)
where X is the datapoint of interest, W is the eigenvectors of interest compiled into a matrix and
Z the outputs of the PCA function. These values were then normalised using equation 5.
Frey et al.[ 15] suggested the use of specific features that could be used to classify char-
acters based on the distribution of the pixels in the image. This was validated on letters and
used by Koen for his implementation of the system, but it was found that transfering these to
digits was feasible as both letters and digits have similarities in their shape (0 is similar to O, 1
is similar to I, 2 is similar to Z, etc.). Frey et al. [ 15]’s more deterministic approach was also

expected as Koen’s implementation [ 4] lost 12% accuracy during his conversion (89.0%

3.5.2 Hyperparameter selection
The hyperparameters of interest that were varied to determine the optimal MLP neural network
for each activation function, is the batch size (number of forward passes before the weights are
updated) and the learning rate. Each network had this training for a maximum of 50 epochs. The
training stopped once accuracy began to decline due to overfitting.
K-fold cross-vaildation was used to spilit the MNIST training dataset to train the net-
work. The technique involves spliting the dataset into k subsets of equal size [ 25]. Training
is done on k−1subsets with the last subset being used to test the network. During every run,
20% of this dataset was kept for validation purposes, and the other 80% was kept for testing
purposes. These parameters were chosen to ensure that there was sufficent data for both training
and testing. K-fold cross-validation was used to reduce the probability of the model’s accuracy
being due to overfitting rather than learning the deeper trends of the data [25],[26] . This spilt is
done randomly, as such seeding could affect results. In order to ensure that the results of the
experiment are statiscally valid, the experiment was repeated 30 times per network for each of
the parameter sweeps, and the accuracy was averaged across the 30 runs.
Batch gradient descent refers to the method wherein the gradient is calculated based on
the error of the entire dataset [ 26][ch.8]. Stochastic gradient descent refers to the method
whereing the gradient in calculated based on the error of smaller batches [ 26][ch.8]. While
batch gradient descent offers lower training times, the regularisation stochastic gradient descent
will further reduce overfitting (hypothesied to be due to the added noise [26][ch.8]). As such,
stochastic gradient descent was chose for use. The use of lower batch sizes was chosen due to
the additional noise (thus further preventing overfitting).
Lower batch sizes need low learning rates to account for the noise associated with them
[26][ch.8]. The parameters chosen there were delibertly chosen to be small to account for this
property. The following batch-size and learning-rate arrays were swept:
• Batch sizes:[8, 16, 32, 64]
• Learning rates:[0.001, 0.003, 0.005, 0.01, 0.03, 0.06, 0.1]

3.6 LIF Neuron Design
3.6.1 Neuron Theoretical Design
The LIF neuron consists of a leak function, a integrate function and a fire function. The leak and
integrate stages are implemented using a resistor-capacitor combination (Figure 3). The neuron
must satisfy two requirements:
1. It must reset the membrane potential to 0 V after every firing event, implementing the hard
threshold described by Eshraghian et al. [5].
2. It must produce spikes with a consistent width, while the firing frequency varies with the
summer-output magnitude (higher summer outputs produce higher firing frequencies) to
implement the fire function
The voltage across the capacitor must be reduced to 1 V during the reset. While options
such as current mirrors and capacitor charge distributions were considered to remove
charge from the membrane threshold, this was not considered viable due to the number of
components required for these circuits to be implemented. Furthermore, due to the soft reset
not being viable in the analogue domain, such complex circuitry was not neccessary as the
threshold needs to be bought to 0 V , which can be done by connecting the membrane voltage to
ground for a period long enough such that the charge stored in the capacitor can be dropped to 0 V .

A switch that is turned on by a digital input was required for use in this system , and
the SN74HC4066 was chosen due to high avaliability for the PCB manufractuer (JLCPCB).
This chip however contains four of these modules [29], so 1 chip can be used for four neurons,
which will have to be accounted for when routing.
The neuron must fire once the voltage drops below 1 V . A comparator is a component
that can output high when one voltage is greater than another, as such this component was
chosen. Furthermore, a comparator can perform this in a single chip rather than having multiple
components to perform the same function, thus reducing the size of the final circuit.
Hysteresis was not added to this comparator as the small spikes that occur close to 1 V
will result in such little spikes that they should not affect the final results. This was accounted for
during the resistor mapping of the neural network created using the LIF neuron.
During the design of the reset function, it was mentioned that the node that represented
the membrane threshold must be connected to ground for a sufficently long enough time for the
discharge to occur. The reset will be instaneous, as such a method must be developed to increase
the length of the spike such that the node can be completely discharged. Other implementations
[30] used ALU’s and other complex components to meet this function, which violates the
requirements of the system.

citor and an additional comparator. The output of the inital comparator will be strected by the
resistor and the capacitor. This strected value will then be the input to another comparator with a
lower voltage threshold (0.5 V) such that is will be on for longer than the inital one is on for,
thus giving the membrane potential sufficient time to be discharged to 0 V . The additional time
for which the circuit will stay on (τstretch) can be represented by Equation 36:
τstretch=R stretch⋅Cstretch (36)

3.10 Hybrid Network
In order to manage the time contraint and the GBP problems mentioned in section 3.10, the
decision was made to rather use a hybrid neural network than a complete SNN.
The hybrid network is a design that involves the MLP neurons being placed in the hid-
den layer, with the LIF neurons in the output layers. The LUT that was created was used as the
surrogate gradient to train the output layer neurons, with the saturated RELU function used as
the gradient of the MLP neurons. The operational amplifiers would not be summing pulses,
rather DC voltages where the GBP will not be a factor. All of the circuitry required to build
this network has already been indepently verified, and as such sufficent confidence existed to
consider this network feasible in the analogue domain. The value of the maximum weights, are
kept from the training of the SNN.

3.10.2 Optimal brain damage
Methods of reducing the number of connections and components used were explored. The
most efficent way to remove many connections at once is to remove an entire neuron from the
network, which is refered to as optimal brain damage [ 2]. The effects of removing a neuron
should be absorbed by the other weights and biases in the network. The removal of a neuron
reduces the amount of resistors needed in the network by 27 resistors (16 inputs to the neuron,
10 output weights, and the 1 bias weight) alongside all the components of the actual neuron.
This process can only be done on the hidden layer neurons, as there must be 10 output layer
neurons due to the 10 possible digits that a data entry can be classified into.
Each neuron in the network was removed one at a time to find the one that will cause
the lowest drop in accruacy, after which the network was trainined for 10 epochs to regain
accuracy. This process was repeated until the network consisted of only 12 neurons. The results
of this operation on the hybird neural network can be seen in Figure 32. The top x-axis refers to
how many resistors will be in the final circuit, which decreases per neuron removed.

3.11 PCB Design
3.11.1 Physcial stackup of the PCB
The use of components that require various distinct operating voltages to functions (+15V and
-15V for the operational amplifiers,+5V for the comparator and bias voltages and 3.3V for the
comparator outputs and bias voltages) meant that routing all of these voltages on 2 layers would
require a significantly larger PCB to route all traces used to power components . The amount of
ground traces required to connect all the ground’s with one another would also increase the size
of the circuit. In order to minimise the size of the final network PCB, it was designed as a 4-layer
PCB. The use of the ground plane had the added benefit of increasing the signal integrity across
all traces in the system [40]. It was placed in the second layer as the majority of components
(sources of cross talk) is present there, and so the shielding offered by the ground plane was
placed as close as possible to the source.
The physical stackup of the PCB is shown in Figure 34. The top and bottom layers are
used to route connections between components. The ground plane was placed in the second
layer to prevent any noises from the power plane affecting the signals in the top layer (where
most of the signals are routed on). The bottom plane has components in order to reduce PCB
size. A few output layer traces were routed on the power routing plane to efficently use the space

available without using too many vias.

3.11.2 Resistor routing
Each neuron would have a maximum of 17 (16 input and 1 bias) weights associated with it. As
each weight is a resistor, finding a strategy to route connections between all of the weights and
the neuron they feed is neccessary to efficently use the space available. The traces will also
have to be routed such that traces on the same layer do not overlap. These constraints called
for the development of a routing strategy that is represented in Figure 35. All weights in the
same column are associated with the same input voltage, and the weights in the same row are
associated with the same output summer that the weights feed. The small circles in the figure
represent the vias used to swap between the layers.
The red and yellow traces are located on the first layer (red layer in Figure 34) and the
purple and green traces are on the bottom layer (blue layer in Figure 34). The red traces in
Figure 35 is used to connect all weights that are associated with the same input voltages. The
yellow traces are used to connect the weighted voltage to the relevent sign that it is associated
with (positive or negative). The postive and negative traces are then connected to the relevent
summers through the red traces that are routed in-between the weights. The traces are shown to
jump over each other for visual clarity, however this does not reflect the behaviour of traces in
the final circuit. An example of the strategy being used in the PCB design is shown in Figure 36.

5. Discussion
5.1 Critical evaluation of the design
5.1.1 Interpretation of results
Throughout the development of the hybrid network, the inital accuracy achieved in software
was 91.08%, with this decreasing to 89.61% after every weight was mapped to resistors. While
a drop of 10% was expected when converting from the software simulation, this proved not to
be the case as the final network achieved an average accuracy of 88.3%, which is only a drop
0f 0.9%. This accuracy is 13.3% higher than the 75% accuracy that was aimed for, as such the
accuracy requirement can be met. These requirements were met alongside having 16 inputs.
The only components used to create the network were simple semi-conductors and discrete
components. As such, all requirements specified in the proposal are met.
The high accuracy achieved also validates the method used to train the hybird net-
work. The process of using a bench neuron’s performance under different voltages to create a
custom gradient allowed for easier way to absorb non-idealities without having to account for
every single one individially. Not all idealities were accounted for as the circuit’s accuracy
did still drop, however this can be attributed to differences between a breadboard and PCB.
Breadboard’s have more parasitic capacitance that can affect output frequencies, but this is not
expected to have played a major role as the less capacitance should impact every neuron.
This behaviour can be better explained in the process through which the surrogate
gradient was created. Due to a lack of components and time, only one bench neuron was
used to create the surrogate gradient. This result can not be considered statically significant
since differeing components can lead to deviances [44]. A more accurate system could have
possibly been acheived if the surrogate gradient was created using the behaviour of multiple
neurons and using the average performance to create the gradient to account for variations in
component behaviour. There could also be differences in performance between each neuron
(due to the different components used). This violates a condition assumed by the software
simlulation: that every neuron had identical performance.
The operating window of the PCB neuron is higher than that of the breadboard neuron, which
is known due to the fact that for output classes in the software simulation where there were
very low frequency outputs (around 70kHz), the hardware equivalent prodcued no output
for those same data points. The use of the operating window to ensure every neuron had
some kind of output for every input provided to it did not hold in the circuit. This may be
due to the component tolerances mentioned before. A stronger candidate emerges when
acknowledging that the breadboard neuron was made using 10% tolerance resistors, the PCB
neurons were made using 1% tolerance. The variation in resistor value shift the operating
window caused by changes to the Rl and Ri (as denoted in Figure) moved the operating
window. The component tolerances of those resistors resulted in the operating window
being shifted higher. This is further backed up by the the hardware output frequencies being

lower, the ordering is not affected). Measuring the operating window of the neuron on

Results between boards is shown in Table 14. As all discrete components used (ex-

The LIF neuron developed in this imWhile this may appear as a redundant structure, the LIF

5.1.4 Strong points of the design
The design is a proof of concept for the LIF neuron in the analogue domain using discrete
components and simple semi-conductors shows that a SNN in the analogue domain is feasiable.
The methodology of creating a surrogate gradient using the performance of the neuron is one
that can be used during the designs of other analogue SNN’s or neural networks in general.
This decision meant that there would be less deviation between the system and the software
simulation without having to explictly account for each analogue non-ideality in the creation
of the simulation (it was all represented in the surrogate gradient, and the saturated RELU
used to train the MLP).
The outputs of the system stay within digital logic levels, which makes converting
the outputs from the analogue domain to the digital one easier (which was done by the
testing system designed). This increase in interfaceability shows that SNN’s or Hybrid
neural networks such as this one should rather be used when using the system for real-world
applications due to the range of their voltage output. This methodology of using LIF neurons at
just the output layers can be also be considered for use in other analogue neural networks.The
increased interfacability meant that the entire dataset could be run through the network with
relative ease and a result could be measured outright (as compared to Koen9 who was not able
to run the entire dataset through his circuit due to a lack of time).
The circuit size was minimised through efficent routing techniques and double sided
component placement (alongside the use of a ground plane), with the routing technique used
being a solution for other neural networks to efficently route large amounts of weights.
The system is able to acheive an accuracy of at least one order or magnitude above
the specifications of the system. The result was also at similar levels of magnitude to
comparable ones made in literature that had more inputs and were larger in neuron size and
number of weights.

6. Conclusion
6.1 Summary of the work completed
This report describes the implementation of an Analogue Neural Network used for digit
recognition. A literature survey was conducted to examine previous implementation of the
network and understand the complexity of the project. 16 inputs were chosen out of a possible
23 through a greedy search to determine the ideal permuations of inputs to prioirtise accuracy.
Networks with RELU, tanh and sigmoid activation functions, alongside a SNN were simulated
in software to determine which proved most feasiable for implementation in the analogue
domain. The SNN was chosen for implementation.
An LIF neuron was designed, simulated using LT-Spice and built to see the feasibil-
ity of the SNN. The performance of this neuron was used to create a surrogate gradient for
the SNN. A neuron design was finalised and a digital SNN was trained using the analogue
non-idealities. Pulse summing concerns (caused by a time contraint) meant that it could not be
implemented properly. The decision was made to switch to the hybrid neural network that
was a combination of a MLP neuron and the proposed LIF neuron. The hybrid network was
converted trained and its weights were converted to equivalent resistor values. While network
size reduction techniques were investigated, the student did not use them due to the impact on
cost of the PCB being negligiable. The network was made as a PCB (which was designed
using KiCAD) and manufactured by JLCPCB. The accuracy of the network was measured to
be 88.3%. The system performs most strongly with identifying 1’s and 4’s, with the worst
performing digits being 5.
The final circuit was tested using a test system that was specifically designed for this
purpose, which is shown in Appendix C. The list of all components used to create the circuit is
in Appendix E.
6.2 Summary of observations and findings
The student was able to create a analogue neural network that met The methodology used by
the student to pick the correct features for use in the analogue neural network is a technique
that can be used for many other optimization problems where the number of inputs of a system
needs to be reduced.
The designed network was able to exceed the accuracy specified (88.3% vs 75%) while adhering
to the other design contraints.
The project shows that a LIF neuron can be designed using simple semiconductors and discrete
components such that it can be used to create a full SNN.
The student has met all relevent requirements specified in the project proposal.
