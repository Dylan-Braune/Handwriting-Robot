HCM40M.T. BrauneMrBraune D.R23539195 Prof. H.C. MyburghHandwriting robotThe need for handwriting still exists for authenticity, ease of communication and personal touches. The problem is thatmany individuals do not possess the time, skills or ability to write neatly and legibly. This leads to the solution presentedin this proposal: a handwriting robot capable of recognizing a user's handwriting style and being able to replicate it.The proposed solution is a handwriting robot capable of training on multiple different user's handwritten text (using apage-scanning rig to capture the handwritten page like the one seen in the image) and being able to produce any desiredpiece of text in any of these user's writing styles (using a text reproduction rig like the one seen in the image). The systemwill be able to recognize which user authored a piece of text and identify what text was written (shown to the userthrough a display as seen in the image). A gantry with 2-dimensional movement will perform actions with a pen toautomatically reproduce the desired text.

1. Text image processing will be performed from first principles, including the isolation of letters from an image of various fonts and sizes of handwritten text.2. A neural network will be designed and trained from first principles to be able to categorize text to different user's styles based on certain style elements, and identify the text written.3. A gantry rig will be designed to be capable of performing the necessary precise 2-dimensional movements using a pen, whilst holding the pen and paper securely in place.4. Pen path planning will be implemented, which involves the conversion of written characters to a 2D motion the gantry needs to perform, and then mapping the movement to steppermotor controls.1. Image processing and deep learning will be performed on a single board computer (instead of on a personal computer), which has limited memory, storage and power.2. Smooth motor control will be needed to produce precise and consistent pen movement to create accurate text.3. Near real-time classification of handwritten text and reproduction of digital text on paper will need to be achieved.There are three main modes of operation for the handwriting robot: training, classification and reproductionTraining/Classification: First, the user will input their page of handwritten text to the scanner (FU 1.1). The user will select to either train or classify, and will input the intended digitaltext alongside this through an input interface. Once the page is scanned, a camera USB driver will be used to transfer the image to the single board computer (FU 1.2). The image willbe conditioned first to fix warping or noise in the image (FU 2.1), and then the character separation will occur. This will separate the page characters (or groups of characters that areconnected) to match the desired neural network input size (FU 2.2). The difference between training and classification occurs here: if the 'training' option is selected, the separatedcharacters will be used to adjust the neural network neuron weightings against the desired digital text that was input (FU 2.4). Each separated character or group of characters will alsobe converted into a trajectory map (coordinate map of required pen motion) (FU 2.5). This trajectory map will be stored permanently within the system (FU 2.6). If the 'classify' optionis selected, the separated characters or group of characters will be passed into the trained neural network classifier (FU 2.3), and the corresponding digital text and detected user will beoutputted to the display interface.Reproduction: If the user sends a 'write' instruction, the digital text and user style desired to be reproduced will be provided. The corresponding trajectory for each character/group willbe retrieved from storage (FU 2.7), and will be converted into stepper motor controls required to produce the desired pen movements (FU 2.8). These stepper motor controls will besent to the corresponding motors via a stepper motor driver to allow for forward and reverse movements (FU 3.1). The x-motor, y-motor and pen lift mechanism will be controlledthrough the stepper motor driver (FU 3.2/3.4). After the pen has been adjusted and is held securely by the pen holder in the robot (FU 3.3), precise handwritten imitations of eachcharacter will be written.
