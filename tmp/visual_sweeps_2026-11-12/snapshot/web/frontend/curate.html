Curate letterforms

The filters that choose which variants to keep score how typical a shape is, and that cannot tell a badly cut letter from an unusual one — so a glyph that is simply wrong can survive. Click any variant to mark it for removal, then save. The original profile is never written over.

nothing marked

Saving writes <writer>_curated.json beside the original and rebuilds the three things derived from the variant set — the prototype letterform, the most typical real variant, and the letter advances — using the same code the profile builder uses. It appears in the Write page's writer list straight away, so the two can be compared without a restart. connectedness is carried over unchanged: it counts adjacent letter pairs seen while reading the pages, and which letter sat next to which is not stored in the profile, so it cannot be recomputed here. The saved file records that in a curatedNote field.
