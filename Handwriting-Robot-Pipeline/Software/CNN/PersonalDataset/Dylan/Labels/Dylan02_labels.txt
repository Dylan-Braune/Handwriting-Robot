image is then converted to a binary ink mask using
adaptive thresholding: for each pixel, a local mean is
computed over a surrounding window and the pixel is
classified as ink if it's darker than the local mean
by more than a fixed margin. A colour-mask
separately flags red/coloured ink so it can be
excluded from the black/blue ink pass, and
small isolated blobs are removed.
The camera is rarely square to the page, so a
rotation angle is estimated by searching over a range
of candidate angles, rotating the binary ink mask
by each candidate, picking the angle that maximises
the variance of that profile. The chosen angle
is applied to the whole page through an affline
rotation before any line grouping happens, since it
assumes horizontal lines. A second pass fixes any
errors from the first one.
Ruled notebook lines are detected as long, thin,
low-height connected runs (measured through
run-length encoding along each row) and removed,
but only after checking that removing them wouldn't
also delete a component that's actually a real hand-
drawn rule. This is done by comparing local ink
darkness, since printed/faint rules are consistently
lighter than pen strokes.
