The recognition network is a hybrid convolutional-
recurrent model. The input is a single-channel line
image resized to a fixed height and width. It passes
through three convolutional stages, each a stack of
three by three convolutions followed by batch
normalization and a ReLU nonlinearity, with channel
counts increasing 32 to 64 to 128 across the
three stages (12 layers in total). A 2 by 2 max-pool
follows the first and second stages only, halving
both spatial dimensions each time. An adaptive
max-pool collapses whatever height remains down
to exactly one row.
The sequence is fed into a two-layer
bidirectional LTSM with hidden size 256 per
direction. At each timestep the forward and
backward hidden states are concatenated into a
512-dimensional vector, which is passed through
a single layer projecting to N+1 logits followed
